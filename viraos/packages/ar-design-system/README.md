# @ar-platform/design-system
## Sistema de Design Unificado Multi-Marca • AR Mídias Integradas

Pacote oficial de design tokens, estilos blueprint técnicos e motores de tema para o ecossistema AR OS.

---

## Marcas Suportadas
1. **VIRA** (`data-theme="vira"`): Forest Green • Infraestrutura Pesada e Compósitos.
2. **Verdis** (`data-theme="verdis"`): Leaf Green • Soluções Baseadas na Natureza e Restauração Ecológica.
3. **Replasticando** (`data-theme="replasticando"`): Ocean Teal • Rastreabilidade e Gestão de Resíduos.
4. **RecicloBike** (`data-theme="reciclobike"`): Solar Amber • Micrologística Urbana e Mobilidade Ativa.
5. **MUTA** (`data-theme="muta"`): Terracotta Raw • Mobiliário Urbano e Placemaking.

---

## Instalação e Uso
```html
<link rel="stylesheet" href="tokens.css">
<script src="themeSwitcher.js"></script>
<script>
  arThemeSwitcher.init();
  // Alterna dinamicamente entre marcas
  arThemeSwitcher.setTheme('verdis');
</script>
```
